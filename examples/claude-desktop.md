# Claude (claude.ai and Claude Desktop)

1. In Wagent, open **Agents → Add agent** and copy the private link (`https://mcp.wagent.sh/c/<connection_id>/mcp`).
2. In Claude: **Settings → Connectors → Add custom connector**. Paste the link and save.
3. Claude opens a sign-in. Approve with the code Wagent sends to your own WhatsApp.
4. Ask: "List the WhatsApp chats you can see." You'll only see chats you set to Read, Draft or Send.
